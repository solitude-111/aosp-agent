# AOSP CVE 数据集

`cases/` 中的案例均来自原始 `AI辅助漏洞回合背景和问题说明.docx` 列表，包含 CVE-2025-48550、CVE-2025-48595 和 CVE-2025-48533。运行输入仅包含案例身份、Git 提交、仓库路径、允许修改文件和管理员配置的验证命令。影响结论和迁移方法必须由 agent 根据代码独立推导。

`oracles/` 保存此前人工分析的影响假设、迁移参考和 PoC 资料状态，供离线评估使用。它们是历史参考，未经独立复核不能视为最终真值；运行时不得将此目录挂入 agent 工作区或加入模型上下文。旧 JSON 中的 `impact`、`migration`、`poc` 仍可加载，但加载器丢弃其值。

`files` 同时列生产文件和允许新增的聚焦测试文件，必须是准确的仓库相对路径，不允许 Git 元数据目录、路径穿越或 glob。`validation` 必须是可信管理员提供的 argv 数组；加载器拒绝直接 shell 调用，但这不构成通用命令安全沙箱。PoC 不进入运行输入，也不会作为验证命令执行。

新增案例时应先确认 Android 16 修复提交和父提交、Android 12 基线的 Git 对象都可读取。结构化影响报告由 `prompts.IMPACT_SCHEMA` 定义；`parse_impact_response` 检查格式，运行引擎还需对照相应 Git blob 验证引用的路径、行号和代码片段。

## 已发现的后续构建接口问题

当前模块构建脚本按 run 管线的 worktree 相对目录寻找补丁和真实仓库；diff 的 workspace/repositories 布局不同。接自动编译前必须增加控制器持有的显式补丁、仓库、基线契约。
脚本 EXIT 恢复 trap 在干净基线确认前启用，需移到确认之后并保留失败恢复的最终退出码，才能保证拒绝脏树时不清理用户改动。
